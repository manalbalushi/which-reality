## Action & Evidence Tracker

This branch also contains a separate application: an **Automated Action
Management & Evidence Tracker** — a working prototype that replaces a
manually maintained Excel action tracker with a centralized system where
actions, updates, comments, evidence, review and a management dashboard are
all linked by a single Action ID.

See [`docs/DESIGN.md`](docs/DESIGN.md) for the full analysis (architecture,
data model, screens, Excel migration, automation flows, and risks) and
[`action_tracker/README.md`](action_tracker/README.md) to run it.
