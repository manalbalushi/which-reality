Import Existing Excel Tracker

Upload your current Excel action tracker. The original file is kept untouched under the server's import archive — nothing is overwritten or deleted. You'll map its columns to the new fields on the next screen before anything is imported.

The first row must be column headers. Data starts from row 2.
What happens next
  1. We read the column headers from your file and suggest a mapping automatically.
  2. You review/adjust the mapping and see a preview of the first rows.
  3. On confirmation, each row becomes a new Action with a system-generated Action ID. Your original reference (if any) is preserved as a Legacy Reference.
  4. Rows missing a title are skipped and listed in the summary - the original file is untouched so you can fix and re-import if needed.
